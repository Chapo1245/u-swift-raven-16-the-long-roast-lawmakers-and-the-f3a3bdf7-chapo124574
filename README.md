The roast sets up the lawmaker's authority (six months drafting a 400-page AI safety bill) and undercuts it with one specific, familiar humiliation: the bill itself circulating as a Word file named `FINAL_v2_FINAL (2).docx` because nobody in the room knew how to make a PDF.
